## Purpose

This folder contains draft materials for the university ethics submission and later usability testing. They are ready for academic review, but they are not evidence that ethics approval has been granted.

## Files

| File | Use |
|---|---|
| `participant-information-sheet.md` | Give to participants before they decide whether to take part. |
| `consent-form.md` | Consent checklist for each participant. |
| `recruitment-screening.md` | Helps avoid recruiting people who may treat the prototype as benefits advice. |
| `usability-test-script.md` | Moderator script and observation structure. |
| `task-list.md` | Scenario-based tasks for the usability session. |
| `post-test-questionnaire.md` | Likert and open questions after the session. |
| `risk-data-privacy-notes.md` | Ethics, data minimisation, UK GDPR and risk notes for submission. |
| `ethics-submission-checklist.md` | Practical checklist before using the SSU portal. |

## Boundary

VERISSIMO is not an official benefits advice service. The study evaluates usability, clarity and explainability of a prototype. Participants must use fictional scenarios and should not enter real personal, health, financial or immigration information.
