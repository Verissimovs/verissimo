# Usability Test Script

## Session Setup

Prototype URL: `https://verissimo-tawny.vercel.app`

Session length: 30 to 45 minutes.

Data collection: task notes, usability observations, post-test questionnaire, anonymised quotes.

Do not record real personal, health, financial, immigration or benefits details.

## Opening Script

Thank you for taking part. Today we are testing VERISSIMO, a web prototype created for a computing dissertation. We are testing the prototype, not you.

VERISSIMO is not an official benefits advice service and it does not make real benefit decisions. Please use only the fictional scenario information I give you. Do not enter your own personal, health, financial or identity details.

You can stop at any time, skip any task, or ask for a break. If anything feels uncomfortable, tell me and we will move on or stop.

Please think aloud if you can: say what you are looking for, what you expect to happen, and anything that feels unclear.

## Consent Check

Confirm:

- participant has read the information sheet,
- participant has completed the consent form,
- participant understands the prototype is not official advice,
- participant understands they should use fictional data only.

## Moderator Rules

- Do not give benefits advice.
- Do not explain how to complete the UI unless the participant is stuck for more than two minutes.
- If helping, record what help was needed.
- If the participant starts sharing real personal circumstances, stop and remind them to use only fictional data.
- If the participant becomes uncomfortable, skip the task or end the session.
