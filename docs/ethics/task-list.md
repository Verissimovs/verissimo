# Usability Test Task List

Use fictional data only. The participant should not enter their real personal information.

## Task 1 - First Impression And Disclaimer

Ask the participant to open VERISSIMO and describe what they think the tool does.

Observe whether they notice:

- it is a benefits eligibility support prototype,
- it is not official advice,
- they should check GOV.UK or a welfare adviser.

## Task 2 - Attendance Allowance Ordinary Scenario

Scenario:

Margaret is over State Pension age. She lives in England and has a long-term physical condition. She needs help with personal care during the day. This has lasted more than 6 months. She is habitually resident in the UK, has been in Great Britain for the required period, is not subject to immigration control, does not receive PIP, DLA, ADP, SADLA or AFIP, and is not in a local-authority funded care home.

Goal:

Complete the questionnaire using this fictional scenario and reach the results page.

Expected observation:

Participant can complete the guided flow and identify Attendance Allowance as likely eligible under ordinary rules.

## Task 3 - Explain The Result

Ask:

"Why did the prototype produce this result?"

Expected observation:

Participant can find the result summary, rule trace and key criteria.

## Task 4 - Find Official Sources

Ask:

"Where would you click to check the official source for one of these rules?"

Expected observation:

Participant can find GOV.UK links in the criteria trace.

## Task 5 - Evidence Recommendation

Ask:

"What evidence does the prototype suggest preparing, and why?"

Expected observation:

Participant can find recommended evidence and understand that it is derived from the assessed criteria.

## Task 6 - Simpler Explanation

Ask:

"Use the simpler explanation feature. Is the explanation clearer than the original result?"

Expected observation:

Participant understands the simpler explanation and does not think it changes the eligibility result.

## Task 7 - Printable Report

Ask:

"Find how to create a report that could be taken to a welfare adviser."

Expected observation:

Participant can use the print report feature and understands it is a support document, not an official decision.

## Task 8 - Optional Sensitive Scenario: End-Of-Life Rules

Only use this task if the participant is comfortable continuing.

Scenario:

A health professional has said that a fictional person may have 12 months or less to live. The person is over State Pension age, lives in England, has care or supervision needs, is habitually resident, meets the Great Britain presence requirement, is not subject to immigration control, does not receive an overlapping disability benefit, and is not in a local-authority funded care home.

Goal:

Check whether the prototype shows the special rules path and SR1 evidence.

Expected observation:

Participant can see that this is a separate special-rules path and can skip the task if uncomfortable.
